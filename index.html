BUILT TO BE EXPLAINED

Every decision
has a reason.

01 / NO FUTURE LEAKAGE

Learn from the past.

Frequency, recency, burstiness, file size, read and write ratios, request size, and current tier feed the model. Future labels are reserved for evaluation.

02 / PAYBACK POLICY

Make the move count.

Benefit = predicted accesses × latency saved. Cost = file size ÷ bandwidth. A hot file must satisfy the payback threshold before promotion.

03 / FEEDBACK

Observe what happened.

The Python feedback stage compares predictions with actual accesses and adjusts heat scores. It does not retrain the regression model. The explorer shows those saved predictions.
